How to write a command

Use this exact order, with a positive amount and two decimal places.

PAY amount USD TO supplier FOR invoice AS request

Suppliers: harbor-supply or cedar-parts. Invoice and request names use letters, numbers, and hyphens. Use a new request name for each new payment.
